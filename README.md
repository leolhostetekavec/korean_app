# korean_app
This apps main goal is quick learning of the Korean language for a native french speaker. It includes 3 parts:
- The PronunciationEngine
- The Application
- The LanguageContent

The PronunciationEngine is the parts that decodes the Korean Hangul characters and converts them into a french native pronunciation.
The Application is the actual learning app with lessons, language islands, phrase rehearsal and much more.
The LanguageContent is the definition the structure of the lessons and islands and the learning path the app follows in order to teach
the user Korean.
